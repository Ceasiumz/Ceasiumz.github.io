问题 1 (30分). 判断正误
考虑一个标准形式的线性规划（LP）及其约束集 $P = {x|Ax = b, x \ge 0}$。假设矩阵 $A \in R^{m \times n}$ 且其行是线性独立的。对于以下每个陈述，请说明其是真还是假，并解释您的答案（如果为假，请举例说明）。

(a) 所有最优解的集合（假设存在）必须是有界的。 答案： 假。 解释： 即使最优目标值是有限的，最优解集也可能无界。例如，如果目标函数与无界可行域的一个边界平行，那么沿着该边界的整个线段或射线上的所有点都可能是最优解，形成一个无界的最优解集。如果问题是无界的，这意味着目标函数值可以无限改善（例如，对于最小化问题可以减小到负无穷），那么最优解集肯定也是无界的。


(b) 在每个最优解处，不能有超过 m 个变量为正。 答案： 假。 解释： 线性规划的基本定理指出，如果存在最优解，那么至少存在一个最优解是基本可行解（BFS）。而基本可行解最多有 m 个正变量（m 为约束条件数）。但是，并非每个最优解都必须是基本可行解。如果存在多个最优基本可行解，它们的凸组合（例如，连接它们的线段上的点）也都是最优解，而这些凸组合中的某些点可能拥有超过 m 个正变量。


(c) 如果存在不止一个最优解，那么存在无数个最优解。 答案： 真。 解释： 线性规划的可行域是一个凸集。如果存在两个不同的最优解 $x_1$ 和 $x_2$，那么连接 $x_1$ 和 $x_2$ 的线段上的所有点，即它们的任意凸组合 $x = \lambda x_1 + (1-\lambda) x_2$（其中 $0 \le \lambda \le 1$）也都是可行解。由于目标函数是线性的，在这些点上的目标函数值都是 $c^T x = \lambda (c^T x_1) + (1-\lambda) (c^T x_2)$。如果 $x_1$ 和 $x_2$ 都是最优解，则 $c^T x_1 = c^T x_2 = \text{最优值}$，因此 $c^T x = \lambda (\text{最优值}) + (1-\lambda) (\text{最优值}) = \text{最优值}$。这意味着线段上的所有点都是最优解。由于线段包含无限多个点，所以存在无数个最优解。


(d) 问题可能没有基本可行解。 答案： 真。 解释： 线性规划的基本定理的第一部分指出，“如果可行集非空，则存在一个基本可行解”。这意味着，只有当可行集是空集时，问题才可能没有基本可行解。如果约束条件相互矛盾，导致没有点满足所有约束，那么可行域就是空的，自然也就没有基本可行解。


(e) 问题可能只有一个基本可行解。 答案： 真。 解释： 如果线性规划的可行域恰好是一个点，那么这个点既是唯一的极点，也是唯一的（退化的）基本可行解。例如，在标准形式下，如果有 n 个变量和 m 个约束 Ax=b，如果 A 的 n 列都线性独立（这意味着 n=m），且 x >= 0 使得 x = A^(-1)b 满足非负性，那么就只有一个基本可行解。


(f) 如果问题的最优值是无界的，那么可行域必须是无界的，反之亦然。 

答案： 假。 

解释：

• “如果问题的最优值是无界的，那么可行域必须是无界的”：这是真的。如果目标函数可以无限地改善（例如，最小化到负无穷），那么这意味着在可行域内存在一个方向，沿着该方向可以无限移动而不会违反任何约束，同时目标函数值持续改善。这直接导致可行域是无界的。

• “反之亦然”（即如果可行域是无界的，那么最优值也必须是无界的）：这是假的。一个无界的可行域不一定导致无界的最优值。例如，考虑最大化 $x_2$，受限于 $x_1 \ge 0, x_2 \ge 0$。可行域是第一象限，是无界的。但是，如果再增加一个约束 $x_2 \le 5$，那么最优值是 5，在 $(0, 5)$ 处达到（或沿着 $x_2=5, x_1 \ge 0$ 的射线），这显然是有界的。另一个例子，最大化 $-x_1$，受限于 $x_1 \ge 0, x_2 \ge 0$。可行域也是无界的，但最优值是 0（在 $x_1=0$ 处），也是有界的。

问题 3 (30分). 基本解和基本可行解

考虑以下线性优化问题：

(a) 将这个线性规划转换为标准形式。 

答案： 标准形式的 LP 要求：
1. 目标函数为最小化。
2. 所有约束条件都是等式。
3. 所有变量都是非负的。

转换步骤：
1. 目标函数： 将最大化 $2x_1 + x_2 + 3x_3$ 转换为最小化 $-(2x_1 + x_2 + 3x_3)$，即 最小化 $-2x_1 - x_2 - 3x_3$。
2. 不等式约束： 引入松弛变量（slack variables）$s_1, s_2 \ge 0$ 将“$\le$”不等式转换为等式。
    ◦ $x_1 + 2x_3 \le 10 \implies x_1 + 2x_3 + s_1 = 10$
    ◦ $2x_2 + x_3 \le 12 \implies 2x_2 + x_3 + s_2 = 12$
3. 非负性： 原始变量 $x_1, x_2, x_3 \ge 0$ 和引入的松弛变量 $s_1, s_2 \ge 0$。
标准形式的线性规划为： 最小化 $-2x_1 - x_2 - 3x_3$ 满足： $$x_1 + 2x_3 + s_1 = 10$$ $$2x_2 + x_3 + s_2 = 12$$ $$x_1, x_2, x_3, s_1, s_2 \ge 0$$

(b) 论证这个问题存在一个最优解。在不显式求解标准形式 LP 的情况下，论证存在一个最优解，其最多只有两个正变量。 

答案： 1. 论证存在一个最优解：
• 可行域非空： 考虑点 $(x_1, x_2, x_3) = (0, 0, 0)$。它满足所有约束：$0 \le 10$, $0 \le 12$, 且所有变量非负。因此，可行域非空。

• 可行域有界：
    ◦ 从 $x_1 + 2x_3 \le 10$ 且 $x_1, x_3 \ge 0$，可知 $x_1 \le 10$ 且 $2x_3 \le 10 \implies x_3 \le 5$。
    ◦ 从 $2x_2 + x_3 \le 12$ 且 $x_2, x_3 \ge 0$，可知 $2x_2 \le 12 \implies x_2 \le 6$ 且 $x_3 \le 12$。
    ◦ 综合来看，$0 \le x_1 \le 10$, $0 \le x_2 \le 6$, $0 \le x_3 \le 5$。

• 由于可行域是非空且有界的（是一个多面体），根据线性规划的性质，此问题必然存在一个最优解。

2. 论证存在一个最优解，其最多只有两个正变量：
• 将原始问题转换为标准形式后，我们有 n=5 个变量 ($x_1, x_2, x_3, s_1, s_2$) 和 m=2 个等式约束。
• 线性规划的基本定理指出，如果存在最优解（我们已经论证了存在），那么存在一个最优解是基本可行解（BFS）。
• 基本可行解的定义是，它最多有 m 个正变量。
• 由于本问题在标准形式下有 m=2 个约束，因此，必存在一个最优解，其中最多只有两个正变量。

(c) 列出标准形式线性规划的所有基本解和所有基本可行解。 

答案： 标准形式 LP 为： 最小化 $-2x_1 - x_2 - 3x_3$ 满足 $x_1 + 2x_3 + s_1 = 10$ $$2x_2 + x_3 + s_2 = 12$$ $$x_1, x_2, x_3, s_1, s_2 \ge 0$$ 矩阵 $A$ 和向量 $b$ 为： $A = \begin{bmatrix} 1 & 0 & 2 & 1 & 0 \ 0 & 2 & 1 & 0 & 1 \end{bmatrix}$，$b = \begin{bmatrix} 10 \ 12 \end{bmatrix}$。 有 $n=5$ 个变量和 $m=2$ 个约束。我们需要选择 2 个线性独立的列来形成基（basis）。基本解的数量最多为 $C(5,2) = 10$。

问题 4 (15分). 极点和松弛变量


考虑多面体 $P = {x \in R^n : Ax \le b, x \ge 0}$。

我们引入松弛变量 $z$ 并构造相应的标准形式多面体 $Q = {(x, z) \in R^{n+m} : Ax + z = b, x \ge 0, z \ge 0}$。 设 $(x^, z^)$ 是多面体 $Q$ 的一个极点。证明 $x^$ 是多面体 $P$ 的一个极点。(提示：使用反证法。假设 $x^$ 不是 $P$ 的极点，意味着它可以表示为 $P$ 中两个不同点的凸组合。然后尝试构造 $Q$ 中两个不同的点来反驳 $(x^, z^)$ 是 $Q$ 的极点这一事实。)

证明： 我们使用反证法来证明。 假设 $x^*$ 不是多面体 $P$ 的一个极点。 根据极点的定义，如果 $x^$ 不是 $P$ 的极点，那么存在 $P$ 中的两个不同点 $y_1, y_2 \in P$，且 $y_1 \ne x^u$, $y_2 \ne x^u$, $y_1 \ne y_2$，以及一个标量 $\lambda \in (0, 1)$，使得 $x^ = \lambda y_1 + (1-\lambda) y_2$。

由于 $y_1, y_2 \in P$，它们满足：
1. $Ay_1 \le b$ 且 $y_1 \ge 0$
2. $Ay_2 \le b$ 且 $y_2 \ge 0$

现在，我们考虑多面体 $Q = {(x, z) : Ax + z = b, x \ge 0, z \ge 0}$。 我们已知 $(x^, z^)$ 是 $Q$ 的一个极点。根据 $Q$ 的定义，$z^$ 满足 $Ax^ + z^* = b$ 且 $z^* \ge 0$。因此 $z^* = b - Ax^u$。由于 $x^ \in P$，我们有 $Ax^* \le b$，这意味着 $b - Ax^* \ge 0$，所以 $z^* \ge 0$ 是满足的。

现在，我们可以为 $y_1$ 和 $y_2$ 构造相应的松弛变量 $z_1$ 和 $z_2$：
1. 令 $z_1 = b - Ay_1$。由于 $y_1 \in P$ 且 $Ay_1 \le b$，所以 $z_1 \ge 0$。
2. 令 $z_2 = b - Ay_2$。由于 $y_2 \in P$ 且 $Ay_2 \le b$，所以 $z_2 \ge 0$。

这样，我们构造了 $Q$ 中的两个点 $(y_1, z_1)$ 和 $(y_2, z_2)$。
• $(y_1, z_1)$ 属于 $Q$，因为 $Ay_1 + z_1 = b$, $y_1 \ge 0$, $z_1 \ge 0$。
• $(y_2, z_2)$ 属于 $Q$，因为 $Ay_2 + z_2 = b$, $y_2 \ge 0$, $z_2 \ge 0$。

接下来，我们证明 $(y_1, z_1)$ 和 $(y_2, z_2)$ 是 $Q$ 中与 $(x^, z^)$ 不同的两个点：
• 由于我们假设 $y_1 \ne y_2$，所以 $(y_1, z_1) \ne (y_2, z_2)$。
• 由于我们假设 $y_1 \ne x^u$，所以 $(y_1, z_1) \ne (x^, z^*)$。
• 由于我们假设 $y_2 \ne x^u$，所以 $(y_2, z_2) \ne (x^, z^*)$。

现在，我们检查 $(x^, z^)$ 是否可以表示为 $(y_1, z_1)$ 和 $(y_2, z_2)$ 的凸组合：
1. 对于 $x$ 部分：$\lambda y_1 + (1-\lambda) y_2 = x^*$ （根据我们的初始假设）。
2. 对于 $z$ 部分： $\lambda z_1 + (1-\lambda) z_2 = \lambda (b - Ay_1) + (1-\lambda) (b - Ay_2)$ $= \lambda b - \lambda Ay_1 + (1-\lambda) b - (1-\lambda) Ay_2$ $= (\lambda + 1 - \lambda) b - A(\lambda y_1 + (1-\lambda) y_2)$ $= b - Ax^$ $= z^$
因此，我们得到 $(x^, z^) = \lambda (y_1, z_1) + (1-\lambda) (y_2, z_2)$。 这意味着 $(x^, z^)$ 可以表示为 $Q$ 中两个不同点 $(y_1, z_1)$ 和 $(y_2, z_2)$ 的严格凸组合。 这直接与 $(x^, z^)$ 是多面体 $Q$ 的一个极点这一事实相矛盾。
因此，我们的初始假设“$x^$ 不是多面体 $P$ 的一个极点”是错误的。**所以，$x^$ 必须是多面体 $P$ 的一个极点。**
