# Windows 鼠标宏

关闭窗口后，程序继续在 Windows 托盘中运行。宏和设置保存在进程内存中，退出程序后清空。

## 启动

在本目录运行 `dotnet run --project .\MouseMacro.csproj`。源码需要 .NET 10 SDK，构建好的程序需要 .NET 10 Windows Desktop Runtime。

## 录制与回放

1. 点击 **录制新宏**，或在 F8 未绑定给已启用宏时按 **F8**。完成操作后按 **F8** 或 **F10** 结束。每次非空录制都会新增一条宏。
2. 选中宏并点击 **设定触发键**，然后按一个键盘键，或在设置窗口外按鼠标左键、右键、中键或两个侧键之一。每个触发键只能分配给一条宏。点击 **取消设定** 可退出按键捕获。
3. 切到目标程序并按触发键，也可点击 **回放所选**。取消勾选行末的 **启用宏** 会同时停用这条宏的快捷键和手动回放。播放中按 **F10** 可停止。
4. 双击托盘图标打开列表。托盘右键菜单也可以录制、停止和退出。

全局触发在宏窗口失去焦点且空闲时启用，触发宏的按键由程序接管。任务栏和托盘上的鼠标点击仍可用于打开设置。F8 若分配给已启用的宏，可通过窗口或托盘菜单开始录制。F10 在空闲时可用于触发宏，在录制或回放时用于停止。

## 宏属性

- **绝对坐标**使用录制时的屏幕位置。**相对坐标**以回放开始时的鼠标位置为原点，保留录制时的位移。
- **跳过空帧**将没有键或按钮按住时的长间隔缩短到最多 250 毫秒，长按和拖动中的停顿保留原时长。
- **结束后鼠标归位**会在正常结束或手动中断时，将鼠标移回回放开始的位置。

Windows 会限制普通权限的程序向管理员权限窗口发送模拟输入。
